How to Set Up 

1) Extract the submission zip.
2) Open a terminal in the PowerTrack/main (where index.html is located).
3) Serve the folder locally (recommended):
If Node.js is available:
npx serve -s . -l 4173
4) Open http://localhost:4173 in your browser.

How to Run
Preferred: Use the deployed link during grading: https://powertrack-50d1f.web.app/

Local (from application/): Run a static server as shown above, then open http://localhost:4173.
